## 2. تجهيز البيئة

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`

**إعدادات المتصفح المطلوبة:**
1. افتح أدوات المطور (F12) → تبويب **Console** — أي خطأ أحمر يظهر هنا يُوثَّق مع البلاغ
2. تبويب **Network** — لعدّ الطلبات في اختبارات النقر المزدوج
3. للاختبار على الجوال: وضع الجهاز (Ctrl+Shift+M) على عرض **375px**

**المتصفحات المطلوبة:** Chrome (أساسي) · Firefox · Safari إن توفر
**المقاسات المطلوبة:** 375px (جوال) و1440px (سطح مكتب) — كل حالة تُنفَّذ على المقاسين

## 3. بيانات الاختبار

### روابط الرحلات

| الحالة | الرابط |
|---|---|
| رحلة عادية (راكبان) | `/trips/000000e1-0000-4000-8000-000000000001?passengers=2` |
| رحلة عادية (راكب واحد) | `/trips/000000e1-0000-4000-8000-000000000001?passengers=1` |
| رحلة منطلقة | `/trips/000000e1-0000-4000-8000-000000000013` |
| رحلة ممتلئة | `/trips/000000e1-0000-4000-8000-000000000014` |
| رحلة غير موجودة | `/trips/000000e1-0000-4000-8000-999999999999` |

### محفزات الأخطاء الحتمية

هذه ليست أخطاء عشوائية — هي **مبرمجة عمداً** لتمكين اختبار مسارات الفشل:

| المحفّز | النتيجة المتوقعة |
|---|---|
| اختيار المقعد رقم **13** | يفشل القفل دائماً برسالة تعارض |
| رقم هاتف ينتهي بـ **00** (مثل `+963911111100`) | يفشل الحجز برسالة تجاوز الحد |

### أرقام هواتف صالحة للاختبار
`+963912345678` · `+963955443322` · `+963998877665`

### أرقام هواتف غير صالحة (يجب أن تُرفض)
`0999123456` (بلا مقدمة دولية) · `+96388123456` (لا يبدأ بـ 9 بعد المفتاح) · `+96391234567` (ناقص رقم) · `+9639123456789` (زائد رقم)

## 4. طريقة تسجيل النتائج

انسخ الجدول أدناه في ملف منفصل أو Google Sheet، وسجّل كل حالة:

| المعرّف | المتصفح | المقاس | النتيجة | ملاحظة / رقم البلاغ |
|---|---|---|---|---|

**قيم النتيجة:** ✅ نجح · ❌ فشل · ⚠️ نجح مع ملاحظة · ⛔ محجوب (لم يمكن التنفيذ)

### قالب البلاغ
```
المعرّف:        QA-B-xx
الأولوية:       P0 / P1 / P2
البيئة:         Chrome 128 / 375px
الخطوات:       1. …  2. …  3. …
المتوقع:        …
الفعلي:         …
Console:        (الصق أي خطأ أحمر)
لقطة/تسجيل:     (مرفق)
```

**تصنيف الأولوية:** P0 = يمنع إتمام الحجز أو يُنشئ حجزاً خاطئاً · P1 = خلل وظيفي بدون بديل · P2 = تجميلي أو له حل التفافي

## المجموعة أ — تفاصيل الرحلة (PAS-3)

### QA-B-01 · عرض تفاصيل الرحلة العادية · P1
**الخطوات:** افتح رابط الرحلة العادية.
**المتوقع:** تظهر جميع العناصر التالية:
- المسار (من → إلى) بالعربية
- وقت الانطلاق والوصول والمدة
- التاريخ بالتنسيق العربي
- بطاقة الشركة: الشعار، الاسم، التقييم
- السعر لكل مقعد مع فاصل الآلاف ورمز **ل.س**
- شارة نوع الحافلة
- تنبيه: «الإلغاء مجاني حتى ساعتين قبل الانطلاق»
- قسم اختيار المقاعد

### QA-B-02 · الرحلة المنطلقة · P0
**الخطوات:** افتح رابط الرحلة المنطلقة.
**المتوقع:** زر الحجز **معطّل**، وبجانبه نص مرئي «انطلقت الرحلة». خريطة المقاعد **لا تظهر إطلاقاً**.
**فشل صريح:** ظهور الخريطة، أو زر معطّل بلا سبب مكتوب.

### QA-B-03 · الرحلة الممتلئة · P0
**الخطوات:** افتح رابط الرحلة الممتلئة.
**المتوقع:** زر معطّل + نص «اكتملت المقاعد». لا خريطة مقاعد.

### QA-B-04 · رحلة غير موجودة · P1
**الخطوات:** افتح رابط الرحلة غير الموجودة.
**المتوقع:** رسالة عربية واضحة أن الرحلة غير موجودة.
**فشل صريح:** شاشة بيضاء، أو رسالة إنجليزية، أو رسالة خطأ عامة «حدث خطأ».

### QA-B-05 · حالة التحميل · P2
**الخطوات:** في Network فعّل **Slow 3G**، ثم افتح رابط الرحلة العادية.
**المتوقع:** يظهر هيكل تحميل (skeleton) رمادي، لا شاشة فارغة ولا قفزة في التخطيط عند وصول البيانات.

### QA-B-06 · ثبات حالة الزر مع الوقت · P2
**الخطوات:** افتح الرحلة العادية، اترك التبويب مفتوحاً **5 دقائق**، ارجع إليه.
**المتوقع:** الصفحة كما هي، الزر ما زال فعّالاً، لا سلوك غريب.

## المجموعة ب — خريطة المقاعد والجنس (PAS-4 AC-1..5)

### QA-B-07 · بنية الخريطة · P0
**الخطوات:** افتح الرحلة العادية واعرض قسم المقاعد.
**المتوقع:**
- شبكة **12 صفاً × 4 أعمدة**
- فجوة ممر مرئية بعد العمود الثاني
- مؤشر **السائق** في مقدمة الحافلة
- ترتيب الشبكة صحيح من اليمين لليسار
- صف الدليل (legend) أسفل الخريطة أو أعلاها

### QA-B-08 · مؤشر الجنس على المقاعد المشغولة · P0
**الخطوات:** افحص المقاعد بحالاتها الأربع.
**المتوقع:**
- المقاعد **المقفلة** و**المحجوزة** تعرض أيقونة جنس (رمزان مختلفان بلونين مختلفين)
- المقاعد **المتاحة** لا تعرض أي أيقونة
- الدليل يحتوي على مدخل لكل جنس + مدخل لكل حالة مقعد
**فشل صريح:** أيقونة على مقعد متاح، أو لونان متشابهان يصعب تمييزهما.

### QA-B-09 · حد عدد المقاعد · P0
**الخطوات:**
1. افتح الرحلة بـ `?passengers=2`
2. اختر مقعدين متاحين
3. حاول اختيار مقعد ثالث

**المتوقع:** المقعد الثالث لا يُختار. المقاعد المختارة تظهر بلون مميز (تعبئة كاملة).
**تابع:** ألغِ اختيار أحدهما → يصبح متاحاً مجدداً وتستطيع اختيار غيره.

### QA-B-10 · حدود المعامل passengers · P1
**الخطوات:** كرّر QA-B-09 مع `?passengers=1` ثم `?passengers=4`.
**المتوقع:** الحد يطابق الرقم في الرابط في كل حالة.

### QA-B-11 · المقاعد المشغولة غير قابلة للاختيار · P0
**الخطوات:** انقر مقعداً مقفلاً، ثم مقعداً محجوزاً.
**المتوقع:** لا يحدث شيء — لا يُختار، ولا رسالة خطأ مزعجة.

### QA-B-12 · شريط الاختيار السفلي · P0
**الخطوات:** اختر مقعدين.
**المتوقع:**
- شريط ثابت أسفل الشاشة
- بطاقة (chip) لكل مقعد تحمل رقمه
- مبدّل **ذكر/أنثى** في كل بطاقة، الافتراضي **ذكر**
- المجموع = السعر × عدد المقاعد، بفاصل آلاف + ل.س
- زر **متابعة** يصبح فعّالاً فقط عند اكتمال العدد المطلوب

### QA-B-13 · تبديل الجنس · P0
**الخطوات:** اختر مقعدين، غيّر الأول إلى **أنثى** وأبقِ الثاني **ذكر**.
**المتوقع:** التبديل فوري ومرئي، ولا يؤثر على المقعد الآخر ولا على المجموع.

### QA-B-14 · بقاء الاختيار عبر التحديث التلقائي · P1
**الخطوات:** اختر مقعدين بجنسين مختلفين، انتظر **35 ثانية** دون لمس الشاشة (الخريطة تتحدث كل 15 ثانية).
**المتوقع:** المقعدان ما زالا مختارين بنفس الجنسين. لا وميض ولا إعادة تعيين.

### QA-B-15 · أهداف اللمس على الجوال · P1
**الخطوات:** على 375px بجهاز حقيقي أو وضع اللمس، انقر عدة مقاعد بالإصبع.
**المتوقع:** كل مقعد قابل للنقر بسهولة (لا يقل عن 40×40 بكسل)، أيقونات الجنس مقروءة دون تكبير.

## المجموعة ج — القفل ومعالجة التعارض (PAS-4 AC-6) ⚠️ الأهم

### QA-B-16 · مسار التعارض الكامل · P0
**الخطوات:**
1. افتح الرحلة العادية بـ `?passengers=2`
2. اختر المقعد **13** ومقعداً آخر متاحاً (مثلاً 20)
3. اضغط **متابعة**

**المتوقع — كل النقاط التالية معاً:**
- المقعد 13 يومض بإطار أحمر لفترة قصيرة
- يظهر إشعار (toast): «تم حجز بعض المقاعد للتو، اختر مقاعد أخرى»
- المقعد 13 **يُحذف** من الاختيار
- المقعد 20 **يبقى** مختاراً
- **تبقى في نفس الصفحة** — لا انتقال لصفحة أخرى
- الخريطة تُحدَّث

**فشل صريح:** الانتقال إلى صفحة الدفع رغم التعارض · حذف المقعدين معاً · شاشة خطأ.

### QA-B-17 · استمرار التدفق بعد التعارض · P0
**الخطوات:** بعد QA-B-16 مباشرة، اختر مقعداً بديلاً واضغط متابعة.
**المتوقع:** ينجح القفل وتنتقل إلى صفحة الدفع. **التدفق لم يمت.**

### QA-B-18 · القفل الناجح والانتقال · P0
**الخطوات:**
1. اختر المقعدين 5 و6
2. اجعل كليهما **أنثى**
3. اضغط متابعة

**المتوقع:** تنتقل إلى `/booking/checkout` والمقعدان مسجلان بالجنس أنثى.

### QA-B-19 · ظهور القفل على الخريطة · P0
**الخطوات:** بعد QA-B-18، ارجع إلى صفحة الرحلة **باستخدام أزرار التطبيق أو زر الرجوع** (لا تحدّث الصفحة بـ F5).
**المتوقع:** المقعدان 5 و6 يظهران **مقفلين** بأيقونة **أنثى**.
> إذا حدّثت بـ F5 ستختفي — هذا متوقع في هذه المرحلة، راجع القسم 1.

### QA-B-20 · تعطيل الزر أثناء المعالجة · P1
**الخطوات:** فعّل **Slow 3G**، اختر مقاعد، اضغط متابعة وراقب الزر.
**المتوقع:** الزر يُعطَّل فوراً ويعرض حالة انتظار. الضغط المتكرر لا يرسل طلبات إضافية (تحقق من عدد الطلبات في Network).

### QA-B-21 · تحرير القفل عند المغادرة · P1
**الخطوات:**
1. اقفل مقعدين (انتقل إلى الدفع)
2. **انتظر 5 ثوانٍ**
3. اضغط زر الرجوع في المتصفح

**المتوقع:** تعود إلى الخريطة والمقعدان **متاحان** مجدداً.

### QA-B-22 · تحرير القفل عند المغادرة السريعة · P1
**الخطوات:** نفس QA-B-21 لكن اضغط الرجوع **خلال ثانية واحدة** من الوصول لصفحة الدفع.
**المتوقع:** المقعدان متاحان مجدداً.
> **ملاحظة للمطوّر:** هذه الحالة تختبر حارساً زمنياً في الكود (400 مللي ثانية). إذا فشلت، وثّقها بدقة — هي نقطة ضعف معروفة ومرشحة للإصلاح في Task 15.

### QA-B-23 · إغلاق التبويب أثناء القفل · P2
**الخطوات:** اقفل مقاعد، أغلق التبويب، افتح الرحلة في تبويب جديد.
**المتوقع:** المقاعد متاحة (أو تصبح متاحة خلال دقائق). لا خطأ ظاهر.

## المجموعة د — العدّاد التنازلي (PAS-5)

> **تحتاج تعديلاً مؤقتاً في الكود — راجع الملحق (أ) قبل البدء، وأعِد القيمة بعد الانتهاء.**

### QA-B-24 · ظهور العدّاد وسلوكه · P0
**الخطوات:** اقفل مقاعد وانتقل لصفحة الدفع.
**المتوقع:**
- عدّاد بصيغة **دقائق:ثوانٍ** مرئي أعلى الصفحة
- يبقى مرئياً أثناء التمرير لأسفل (ثابت)
- يعدّ تنازلياً بدقة كل ثانية

### QA-B-25 · التحذير البصري · P1
**الخطوات:** (بمهلة 150 ثانية حسب الملحق أ) راقب العدّاد حتى يصل تحت **2:00**.
**المتوقع:** يتغيّر لونه إلى اللون التحذيري/الأحمر.

### QA-B-26 · استقلال العدّاد عن ساعة الجهاز · P0
**الخطوات:**
1. اقفل مقاعد وانتقل للدفع
2. غيّر ساعة نظام التشغيل **10 دقائق للأمام**
3. راقب العدّاد

**المتوقع:** العدّاد يواصل العدّ الطبيعي ولا يقفز ولا ينتهي فجأة.
**بعد الاختبار:** أعِد ضبط ساعة الجهاز.

### QA-B-27 · انتهاء المهلة · P0
**الخطوات:** اترك العدّاد يصل إلى **0:00**.
**المتوقع:**
- نافذة حوارية: «انتهت مهلة الحجز»
- **إجراء واحد فقط**: «العودة لاختيار المقاعد»
- الضغط عليه يعيدك لخريطة المقاعد
- المقاعد التي كانت مقفلة أصبحت **متاحة**
- لا يمكن إغلاق النافذة والبقاء في صفحة الدفع

## المجموعة هـ — نموذج الدفع (PAS-6)

### QA-B-28 · حارس الوصول المباشر · P1
**الخطوات:** افتح `/booking/checkout` مباشرة في تبويب جديد دون المرور بالحجز.
**المتوقع:** إعادة توجيه فورية للصفحة الرئيسية.

### QA-B-29 · بطاقات الركاب · P0
**الخطوات:** اقفل مقعدين بجنسين مختلفين وانتقل للدفع.
**المتوقع:**
- بطاقة لكل مقعد، عنوانها رقم المقعد
- حقل الاسم وحقل الهاتف في كل بطاقة
- الجنس يظهر كـ **شارة للقراءة فقط** — لا يمكن تغييره هنا
- رابط/نص تلميح: «لتغيير الجنس عد لاختيار المقاعد»
- الجنس يطابق ما اخترته في الخريطة

**فشل صريح:** إمكانية تغيير الجنس في هذه الصفحة.

### QA-B-30 · التحقق من الاسم · P1
**الخطوات:** أدخل في حقل الاسم: (فارغ) ثم `أب` ثم `أحمد`.
**المتوقع:** الأولان يعطيان رسالة خطأ **بالعربية**، الثالث يُقبل.

### QA-B-31 · التحقق من الهاتف · P1
**الخطوات:** جرّب كل رقم من قائمة الأرقام غير الصالحة في القسم 3، ثم رقماً صالحاً.
**المتوقع:** كل رقم غير صالح يعطي رسالة خطأ عربية واضحة. الرقم الصالح يُقبل.
**تحقق إضافي:** حقل الهاتف يعرض الأرقام من اليسار لليمين بشكل صحيح داخل التصميم العربي.

### QA-B-32 · خانة توحيد الرقم · P2
**الخطوات:**
1. أدخل رقماً صالحاً في بطاقة الراكب الأول
2. فعّل خانة «نفس الرقم لجميع الركاب»
3. ألغِ تفعيلها

**المتوقع:**
- عند التفعيل: يُنسخ الرقم لبقية البطاقات وتصبح غير قابلة للتحرير
- عند الإلغاء: تعود قابلة للتحرير **مع بقاء القيم** (لا تُمسح)

### QA-B-33 · قسم الدفع · P1
**المتوقع:** خيار واحد فقط «الدفع في المكتب»، محدد ومعطّل، مع نص توضيحي. **لا يظهر أي خيار دفع آخر.**

### QA-B-34 · منع الإرسال الناقص · P1
**الخطوات:** اترك الحقول فارغة واضغط **تأكيد الحجز**.

## المجموعة و — إنشاء الحجز والتذكرة (PAS-6/PAS-7)

### QA-B-36 · المسار السعيد الكامل · P0
**الخطوات:** من الصفحة الرئيسية: ابحث → اختر رحلة → اختر مقعدين مع جنسين → متابعة → املأ بيانات صحيحة → تأكيد الحجز.
**المتوقع — صفحة التأكيد تعرض:**
- عنوان نجاح واضح
- **رمز الحجز (PNR)** بارز وقابل للنسخ
- رمز **QR** مرسوم بوضوح
- ملخص الرحلة
- جدول الركاب: المقعد، الاسم، **الجنس**، الهاتف
- المجموع
- إشعار: «ادفع في المكتب قبل الانطلاق بـ 30 دقيقة»
- زر «العودة للرئيسية»

### QA-B-37 · نسخ رمز الحجز · P2
**الخطوات:** اضغط زر النسخ، ثم الصق في أي حقل نصي.
**المتوقع:** الرمز يُنسخ صحيحاً ويظهر إشعار تأكيد.

### QA-B-38 · صيغة رمز الحجز · P0
**الخطوات:** نفّذ **5 حجوزات كاملة** وسجّل كل رمز.
**المتوقع لكل رمز:**

- لا يحتوي على: صفر `0` · حرف `O` · واحد `1` · حرف `I`
- الرموز الخمسة مختلفة عن بعضها

### QA-B-39 · منع الحجز المكرر · P0
**الخطوات:**
1. فعّل **Slow 3G** في Network
2. افتح تبويب Network وامسح السجل
3. أكمل حتى شاشة الدفع
4. اضغط **تأكيد الحجز** ثلاث مرات سريعة متتالية

**المتوقع:**
- الزر يُعطَّل بعد النقرة الأولى
- في Network: **طلب POST واحد فقط** إلى `/api/bookings`
- تُنشأ تذكرة واحدة برمز حجز واحد

**فشل صريح:** أكثر من طلب ناجح، أو تذكرتان.

### QA-B-40 · تجاوز حد الحجوزات · P0

**المتوقع:**

- لا تُنشأ تذكرة
- يمكنك تعديل الرقم وإعادة المحاولة بنجاح

### QA-B-41 · انتهاء المهلة أثناء التأكيد · P0
**الخطوات:** (بمهلة قصيرة حسب الملحق أ) املأ البيانات، انتظر حتى قرب انتهاء المهلة، ثم اضغط تأكيد في اللحظة الأخيرة.

### QA-B-42 · منع الرجوع لصفحة الدفع · P1

### QA-B-43 · حارس صفحة التأكيد · P1

### QA-B-44 · المقاعد بعد الحجز · P0
